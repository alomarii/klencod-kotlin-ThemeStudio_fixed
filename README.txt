استوديو الثيمات (ThemeStudio) - الإصدار 1.1

المتطلبات: Android Studio (Ladybug أو أحدث) + اتصال إنترنت أول مرة (لتنزيل Gradle 8.9).

1) File > Open ثم اختر مجلد ThemeStudio وانتظر انتهاء Gradle Sync.
2) Build > Build Bundle(s) / APK(s) > Build APK(s)
   الملف الناتج: app/build/outputs/apk/debug/app-debug.apk
3) ثبّت الملف وافتح البرنامج، ثم اضغط 🎨 لفتح الاستوديو.
4) من الاستوديو اضغط "اجعل هذا البرنامج الشاشة الرئيسية".

إن ظهر خطأ JDK: File > Settings > Build Tools > Gradle > Gradle JDK
واختر jbr-17 أو jbr-21 (المدمج مع Android Studio).
